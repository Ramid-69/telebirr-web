# Tele Birr Web Clone

A Tele Birr-inspired wallet experience built with Next.js, TypeScript, and Tailwind CSS.

## Features
- Dashboard overview
- Send money flow
- Top-up wallet
- Bill payment pages
- Transactions history
- Profile page
- Login screen

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Tech stack
- Next.js
- TypeScript
- Tailwind CSS
